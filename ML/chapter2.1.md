## 1. 核心思想总览

### 1.1 本章要解决的问题

> 如何用**有限的、带噪声的数据**，推断出背后隐藏的规律？

三个典型场景：
- 看到几个数字（如 16, 8, 2, 64），猜背后的规则
- 抛硬币 10 次，估计正面概率
- 孩子只听过几句话，学会了语言规律

### 1.2 贝叶斯方法的核心公式

$$P(\theta \mid \mathcal{D}) = \frac{P(\mathcal{D} \mid \theta) \cdot P(\theta)}{P(\mathcal{D})}$$

| 符号 | 名称 | 含义 |
|------|------|------|
| $P(\theta)$ | **Prior（先验）** | 看到数据前，对规则的初始信念 |
| $P(\mathcal{D} \mid \theta)$ | **Likelihood（似然）** | 若规则为 θ，数据出现的概率 |
| $P(\theta \mid \mathcal{D})$ | **Posterior（后验）** | 看到数据后，更新的信念 |
| $P(\mathcal{D})$ | **归一化常数** | 确保后验概率之和为 1 |

**类比**：医生先有对常见病的经验（prior），再结合症状（likelihood），最终给出诊断（posterior）。

### 1.3 贝叶斯学习的流程

```
初始假设（Prior）
    ↓
观测数据 D
    ↓
更新信念（Posterior）= Prior × Likelihood / 归一化
    ↓
预测新数据（后验预测分布）
```

## 2. 贝叶斯推断基础

### 2.1 为什么需要贝叶斯方法？

传统机器学习方法需要**正例 + 负例**才能学习分类边界。  
但现实中：
- 负例往往**稀缺**或**无穷多**
- 人类/儿童学习概念**不需要负例**

**贝叶斯方法**：只用正例，通过推断"生成数据的规则"来学习概念。

### 2.2 概率作为不确定性的语言

- 不说"答案是 X"，而是给每个可能的答案一个**概率**
- 数据越多 → 概率越集中 → 不确定性越低
- 保留不确定性是诚实的，也是正确的

## 3. 贝叶斯概念学习

### 3.1 问题定义

**概念学习 = 二元分类**：

$$f(x) = \begin{cases} 1 & \text{如果 } x \text{ 属于概念 } C \\ 0 & \text{否则} \end{cases}$$

### 3.2 儿童学习"狗"的例子

- 儿童只从正例（"看，这是狗！"）中学会概念
- 从未被告知"什么不是狗"
- 心理学研究证实：**人类能从纯正例中归纳概念**

### 3.3 标准分类 vs 贝叶斯概念学习

| | 标准分类 | 贝叶斯概念学习 |
|--|---------|--------------|
| 是否需要负例 | ✅ 需要 | ❌ 不需要 |
| 输出 | 决策边界 | 概念的概率分布 |
| 核心机制 | 拟合数据 | 推断生成数据的规则 |
| 不确定性 | 通常不表达 | 显式表达 |

## 4. 数字游戏：具体框架

### 4.1 游戏规则

- 整数范围：1 到 100
- 我心里想了一个规则 C，从中抽取正例告诉你
- 你需要判断新数字属于 C 的概率

### 4.2 两组数据的直觉对比

| 数据 D | 人类直觉 | 原因 |
|--------|---------|------|
| {16, 8, 2, 64} | 规则 = "2的幂次" | 四个数都是2的幂次，太精确了不像巧合 |
| {16, 23, 19, 20} | 规则 = "接近20的数" | 数字聚集在20附近 |

### 4.3 假设空间 H

定义一个包含所有候选规则的集合：

| 假设 h | 集合内容 | \|h\| |
|--------|---------|-------|
| 2的幂次 | {1,2,4,8,16,32,64} | 7 |
| 偶数 | {2,4,6,...,100} | 50 |
| 10的倍数 | {10,20,...,100} | 10 |
| 质数 | {2,3,5,...,97} | 25 |
| 2的幂次（32除外） | {1,2,4,8,16,64} | 6 |

每个假设 $h \in \mathcal{H}$ 是一个**候选规则**，对应 1-100 中的某个子集。

## 5. Likelihood：消灭可疑的巧合

### 5.1 核心直觉

**"可疑的巧合"原则**：  
如果真实规则是"偶数"（50个数），为什么我们偏偏每次都抽到2的幂次？这太巧了！  
→ 更合理的解释是：规则就是"2的幂次"。

### 5.2 均匀抽样假设

假设正例是从概念集合中**均匀随机抽取**的：

$$P(x \mid h) = \frac{1}{|h|}$$

### 5.3 Likelihood 公式

N 个独立样本的联合概率：

$$P(\mathcal{D} \mid h) = \left(\frac{1}{|h|}\right)^N$$

### 5.4 Size Principle（大小原则）

$$\text{集合越小} \Rightarrow \frac{1}{|h|} \text{ 越大} \Rightarrow \text{Likelihood 越高}$$

**具体计算**（D = {16, 8, 2, 64}，N=4）：

$$P(\mathcal{D} \mid h_{two}) = \left(\frac{1}{7}\right)^4 = \frac{1}{2401} \approx 4.2 \times 10^{-4}$$

$$P(\mathcal{D} \mid h_{even}) = \left(\frac{1}{50}\right)^4 = \frac{1}{6250000} \approx 1.6 \times 10^{-7}$$

$$\frac{P(\mathcal{D} \mid h_{two})}{P(\mathcal{D} \mid h_{even})} \approx 2603 \text{ 倍}$$

### 5.5 Size Principle 的几何直觉

```
如果规则是"偶数"(50个数)：
4次都落在7个2的幂次上，概率 = (7/50)^4 ≈ 0.004 → 太可疑！

如果规则是"2的幂次"(7个数)：
4次全落在集合里 → 完全正常！
```

**类比**：一个精确的地址（上海市徐汇区某栋楼）比模糊的地址（中国某地）更能证明你真的在那里。

## 6. Prior：编码常识

### 6.1 Prior 的作用

给每个假设赋予**先验概率** $P(h)$，反映它在看到数据之前有多合理。

| 假设 | 直觉评价 | Prior |
|------|---------|-------|
| 2的幂次 | 自然、简洁、有数学规律 | 高 |
| 偶数 | 自然、常见 | 高 |
| 2的幂次（32除外） | 刻意、奇怪 | **极低** |
| {16,8,2,64,7} | 完全随意 | **极低** |

### 6.2 Prior 解决 Likelihood 的盲区

**问题**：  
"2的幂次（32除外）"的集合大小=6，比"2的幂次"的集合大小=7 更小，  
所以 likelihood 更高 —— 但人类强烈排斥这个规则！

**原因**：  
Prior 极低（规则太刻意）× Likelihood 稍高 = **后验仍然极低**

### 6.3 Prior 的主观性是优点

同样的数据 D = {1200, 1500, 900}：

- **若告知是算术规则** → Prior 偏向100的倍数，预测 400 可能，1183 不可能
- **若告知是胆固醇水平** → Prior 偏向医学知识，预测 400 极度异常，1183 合理

**Prior = 领域知识 + 常识 + 背景信息**，让同样的数据在不同背景下得出合理的不同结论。

### 6.4 Prior 的三种来源

| 来源 | 例子 |
|------|------|
| 领域专家知识 | 医生知道正常胆固醇范围 |
| 奥卡姆剃刀 | 简单规则比复杂规则 Prior 更高 |
| 历史数据 | 用过去的数据估计 Prior |

## 7. Posterior：合并所有信息

### 7.1 后验公式

$$P(h \mid \mathcal{D}) = \frac{P(\mathcal{D} \mid h) \cdot P(h)}{P(\mathcal{D})} = \frac{P(h) \cdot \mathbf{I}(\mathcal{D} \in h) / |h|^N}{\sum_{h' \in \mathcal{H}} P(h') \cdot \mathbf{I}(\mathcal{D} \in h') / |h'|^N}$$

### 7.2 各符号含义

| 符号 | 含义 |
|------|------|
| $\mathbf{I}(\mathcal{D} \in h)$ | 指示函数：数据与h一致=1，否则=0 |
| $\|h\|^N$ | Likelihood（集合大小的N次方） |
| 分母 $P(\mathcal{D})$ | 归一化常数，使所有后验之和=1 |

### 7.3 计算步骤（重要！）

**第一步**：用 $\mathbf{I}(\mathcal{D} \in h)$ 过滤——数据不在集合里的假设直接归零

**第二步**：计算未归一化后验 = $P(h) \times \frac{1}{|h|^N}$

**第三步**：求所有未归一化后验的总和（归一化常数）

**第四步**：每个未归一化后验 ÷ 总和 = 归一化后验

### 7.4 具体计算示例

D = {4, 16}，N=2：

| 假设 h | \|h\| | P(h) | P(D\|h)=(1/\|h\|)² | 未归一化后验 | P(h\|D) |
|--------|-------|------|---------------------|------------|---------|
| h₁=2的幂次 | 7 | 0.50 | 1/49 ≈ 0.0204 | 0.0102 | **89.8%** |
| h₂=偶数 | 50 | 0.40 | 1/2500 = 0.0004 | 0.00016 | 1.4% |
| h₃=10的倍数 | 10 | 0.10 | — | **0**（4不是10的倍数，直接淘汰！） | 0% |

> ⚠️ **关键**：先检查 $\mathbf{I}(\mathcal{D} \in h)$！4 不在 h₃ 的集合里，h₃ 直接出局。

### 7.5 后验随数据增多的变化

```
D = {16}        → 后验模糊，多个假设竞争
D = {16, 8}     → 后验开始集中
D = {16, 8, 2, 64} → 后验高度集中在"2的幂次"
```

规律：**每增加一个数据点，似然差距被指数级放大**（因为是乘法）。

## 8. MAP 估计与 MLE

### 8.1 MAP（最大后验估计）

$$\hat{h}_{MAP} = \arg\max_h P(h \mid \mathcal{D}) = \arg\max_h \left[\log P(\mathcal{D} \mid h) + \log P(h)\right]$$

- 后验最高的那个假设
- 综合考虑数据（Likelihood）和常识（Prior）

### 8.2 MLE（最大似然估计）

$$\hat{h}_{MLE} = \arg\max_h P(\mathcal{D} \mid h) = \arg\max_h \log P(\mathcal{D} \mid h)$$

- 只看数据，完全不考虑 Prior
- 是 MAP 在 N→∞ 时的极限

### 8.3 为什么数据越多 Prior 越无关紧要？

对数形式：

$$\log P(h \mid \mathcal{D}) = \underbrace{\log P(\mathcal{D} \mid h)}_{\text{随 N 线性增长}} + \underbrace{\log P(h)}_{\text{固定常数}}$$

- Likelihood 项 = $-N \log|h|$，随数据量**线性增长**
- Prior 项 = $\log P(h)$，**固定不变**

→ 数据量足够大时，Prior 可忽略，MAP ≈ MLE

### 8.4 一致性（Consistency）

**定理**：若真实规则 $h^*$ 在假设空间 $\mathcal{H}$ 中，则：

$$\lim_{N \to \infty} P(h^* \mid \mathcal{D}) = 1$$

- 贝叶斯推断是**一致估计量**
- 假设空间在极限下**可识别（identifiable）**

**前提条件**：真实规则必须在假设空间内！

> 类比：在北京找住在上海的人，无论多仔细都找不到——问题不是方法，是搜索范围设错了。

### 8.5 MAP vs Dirac Delta

当后验极度集中在 MAP 时：

$$P(h \mid \mathcal{D}) \to \delta_{\hat{h}_{MAP}}(h) = \begin{cases} 1 & h = \hat{h}_{MAP} \\ 0 & \text{否则} \end{cases}$$

## 9. 后验预测分布

### 9.1 Version 1：抽样概率

$$p(\tilde{x} \mid \mathcal{D}) = \sum_{h \in \mathcal{H}} p(\tilde{x} \mid h) \cdot P(h \mid \mathcal{D})$$

其中 $p(\tilde{x} \mid h) = \frac{1}{|h|}$（均匀分布，受集合大小影响）

**本质**：让所有假设按可信度加权投票（贝叶斯模型平均）

### 9.2 Version 2：归属概率（更常用）

$$p(\tilde{x} \in C \mid \mathcal{D}) = \sum_{h \in \mathcal{H}} \mathbf{I}(\tilde{x} \in h) \cdot P(h \mid \mathcal{D})$$

其中 $\mathbf{I}(\tilde{x} \in h) \in \{0, 1\}$（只看 $\tilde{x}$ 在不在集合里）

**本质**：把所有"包含 $\tilde{x}$"的假设的后验权重加起来

### 9.3 Version 1 vs Version 2 的区别

| | Version 1 | Version 2 |
|--|-----------|-----------|
| 问题 | 从C抽样，抽到x̃的概率？ | x̃属于C的概率？ |
| 核心 | $p(\tilde{x}\|h) = 1/\|h\|$（受集合大小影响） | $\mathbf{I}(\tilde{x} \in h) \in \{0,1\}$ |
| 示例（x̃=32，h₁=2幂次90%，h₂=偶数9%） | $(1/7)\times0.9 + (1/50)\times0.09 \approx 0.131$ | $1\times0.9 + 1\times0.09 = 0.99$ |

### 9.4 计算步骤（Version 2）

以 $\tilde{x} = 32$，后验为 P(h₁)=0.90, P(h₂)=0.09, P(h₃)=0.01 为例：

**Step 1**：检查 32 在不在每个假设里
- 32 ∈ h₁（2的幂次）✅ → I = 1
- 32 ∈ h₂（偶数）✅ → I = 1
- 32 ∉ h₃（2的幂次除32）❌ → I = 0

**Step 2**：加权求和

$$p(32 \in C \mid \mathcal{D}) = 1\times0.90 + 1\times0.09 + 0\times0.01 = 0.99$$

### 9.5 Plug-in 近似

当后验高度集中在 MAP 时，可以简化：

$$p(\tilde{x} \in C \mid \mathcal{D}) \approx \mathbf{I}(\tilde{x} \in \hat{h}_{MAP})$$

| | 完整贝叶斯 | Plug-in 近似 |
|--|-----------|------------|
| 计算复杂度 | 高 | 低 |
| 数据量少时 | ✅ 诚实表达不确定性 | ❌ 严重低估不确定性 |
| 数据量大时 | ✅ 正确 | ✅ 结果几乎一样 |
| 本质缺陷 | — | 把"90%可信"当"100%确定" |

**结论**：数据量少时必须用完整后验；数据量大时 Plug-in 够用。

### 9.6 数据量对预测分布的影响

```
数据量少 → 后验模糊 → 预测分布宽 → 不确定性高（诚实）
数据量大 → 后验集中 → 预测分布窄 → 不确定性低（精准）
```

## 10. Version Space 及其局限

### 10.1 什么是 Version Space

**Version Space** = 假设空间中**与当前数据一致**的所有假设的子集：

$$VS(\mathcal{D}) = \{h \in \mathcal{H} \mid \mathbf{I}(\mathcal{D} \in h) = 1\}$$

即：目前还没被数据"排除掉"的规则集合。

### 10.2 Version Space 的两个致命缺陷

**缺陷一：无法处理 VS 内多个假设之间的分歧**

D = {16}，VS = {偶数, 2的幂次, 4的倍数, ...}

对于 $\tilde{x} = 6$：
- "偶数"说：✅ 在
- "2的幂次"说：❌ 不在

Version Space 无法给出统一答案。

**缺陷二：无法区分质量不同的假设**

D = {16, 8, 2, 64}，VS = {偶数, 2的幂次, 2的幂次除32}

Version Space 认为三个假设**地位完全平等**，但人类直觉强烈偏好"2的幂次"。

### 10.3 贝叶斯的优势

```
Version Space 的世界观：
    假设要么"一致" ✅，要么"不一致" ❌，一致的假设完全平等

贝叶斯的世界观：
    给每个假设赋予概率，量化可信度的差异
```

> **一句话总结**：Version Space 告诉你"谁还活着"，贝叶斯告诉你"谁活得最好"。

## 11. 公式速查表

| 公式名 | 表达式 | 用途 |
|--------|--------|------|
| **贝叶斯定理** | $P(h\|\mathcal{D}) \propto P(\mathcal{D}\|h) \cdot P(h)$ | 核心更新公式 |
| **Likelihood** | $P(\mathcal{D}\|h) = (1/\|h\|)^N$ | 数据对假设的支持程度 |
| **指示函数** | $\mathbf{I}(\mathcal{D} \in h) \in \{0,1\}$ | 淘汰不一致假设 |
| **后验完整式** | $P(h\|\mathcal{D}) = \frac{P(h)\cdot\mathbf{I}(\mathcal{D}\in h)/\|h\|^N}{\sum_{h'}P(h')\cdot\mathbf{I}(\mathcal{D}\in h')/\|h'\|^N}$ | 计算后验 |
| **MAP** | $\hat{h}_{MAP} = \arg\max_h[\log P(\mathcal{D}\|h) + \log P(h)]$ | 最可信假设 |
| **MLE** | $\hat{h}_{MLE} = \arg\max_h \log P(\mathcal{D}\|h)$ | 忽略Prior的MAP |
| **预测 v1** | $p(\tilde{x}\|\mathcal{D}) = \sum_h (1/\|h\|) \cdot P(h\|\mathcal{D})$ | 抽样概率 |
| **预测 v2** | $p(\tilde{x}\in C\|\mathcal{D}) = \sum_h \mathbf{I}(\tilde{x}\in h) \cdot P(h\|\mathcal{D})$ | 归属概率（更常用） |
| **Plug-in** | $p(\tilde{x}\in C\|\mathcal{D}) \approx \mathbf{I}(\tilde{x}\in\hat{h}_{MAP})$ | 数据充足时的简化 |

### 符号速查

| 符号 | 含义 |
|------|------|
| $h$ | 一个候选规则/假设 |
| $\mathcal{H}$ | 全部候选规则的集合（假设空间） |
| $\mathcal{D}$ | 已观测的数据集 |
| $\tilde{x}$ | 待预测的新数据点 |
| $\|h\|$ | 假设 h 的集合大小 |
| $N$ | 已观测样本数量 |
| $\mathbf{I}(\cdot)$ | 指示函数，条件成立=1，否则=0 |
| $\sum_h$ | 对假设空间中所有假设求和 |
| $\arg\max$ | 使函数值最大的那个参数 |
| $\delta$ | Dirac delta 函数（极度集中的概率分布） |

## 12. 常见考试陷阱

### ⚠️ 陷阱一：忘记先检查指示函数

**错误做法**：直接计算所有假设的 likelihood  
**正确做法**：先用 $\mathbf{I}(\mathcal{D} \in h)$ 过滤，不一致的假设直接归零，不参与后续计算

> 例：D = {4, 16}，h₃ = 10的倍数  
> 4 不是 10 的倍数 → $\mathbf{I}(\mathcal{D} \in h_3) = 0$ → h₃ 直接出局！

### ⚠️ 陷阱二：只看 Likelihood 忽略 Prior

**错误想法**："h_B 集合更小，likelihood 更高，所以 h_B 更好"  
**正确思路**：后验 = Likelihood × Prior，Prior 极低可以完全压制 likelihood 优势

> 例："2的幂次除32"的 likelihood > "2的幂次"，但前者 prior 极低，后验反而低得多

### ⚠️ 陷阱三：混淆 Version 1 和 Version 2

- **Version 1**：$p(\tilde{x}|h) = 1/|h|$，结果受集合大小影响
- **Version 2**：$p(\tilde{x}\in C|h) = \mathbf{I}(\tilde{x}\in h)$，只看在不在，输出 0 或 1

### ⚠️ 陷阱四：数据量少时用 Plug-in

- 数据少 → 后验不集中 → Plug-in 严重低估不确定性
- 考试中若问"两种方法的差异"，答案一定涉及**不确定性的表达**

### ⚠️ 陷阱五：误以为 MLE 和 MAP 总是相同

- **数据量大时**：MLE ≈ MAP（Prior 被淹没）
- **数据量少时**：MLE ≠ MAP，Prior 的影响很大
- MLE 完全不考虑 Prior，有时给出不合理结果

### ⚠️ 陷阱六：忘记归一化

计算后验时，**必须除以所有未归一化后验的总和**，否则概率之和不为 1。

## 13. 知识结构总图

```
贝叶斯概念学习
│
├── 动机
│   ├── 儿童只从正例学习概念
│   └── 标准分类需要负例 → 贝叶斯不需要
│
├── 框架
│   ├── 假设空间 H（所有候选规则）
│   ├── Prior P(h)（常识）
│   ├── Likelihood P(D|h) = (1/|h|)^N（数据证据）
│   └── Posterior P(h|D) ∝ Likelihood × Prior
│
├── Size Principle
│   └── 集合越小 → Likelihood越高 → 消灭可疑巧合
│
├── Version Space（传统方法的局限）
│   ├── 只能说"谁一致"，不能说"谁更好"
│   └── 贝叶斯用概率解决这个问题
│
├── MAP 与 MLE
│   ├── MAP = argmax(Likelihood × Prior)
│   ├── MLE = argmax(Likelihood)
│   ├── N→∞ 时 MAP → MLE（Prior被淹没）
│   └── 一致性：真相在H内 → 无限数据必收敛
│
└── 预测
    ├── Version 1：p(x̃|D) = Σ (1/|h|)·P(h|D)
    ├── Version 2：p(x̃∈C|D) = Σ I(x̃∈h)·P(h|D)  ← 更常用
    └── Plug-in：≈ I(x̃∈ĥ_MAP)  ← 数据少时低估不确定性
```
