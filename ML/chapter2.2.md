## 1. 似然函数（Likelihood）

### 核心思想

> **似然函数回答的问题是：如果 θ 是某个值，我观察到这组数据的可能性有多大？**

### 概率 vs 似然

同一个公式，两种视角：

$$P(\text{数据} | \theta) = \theta^{N_1}(1-\theta)^{N_0}$$

| 视角 | 什么固定 | 什么变化 | 问的问题 |
|------|---------|---------|---------|
| **概率** | θ固定 | 数据变化 | θ=0.5的硬币，抛10次，7次正面的概率？ |
| **似然** | 数据固定 | θ变化 | 已经看到7次正面，哪个θ最能解释这个结果？ |

### 一句话

> **概率是已知规则算结果，似然是已知结果猜规则。**

### 能解决什么问题

凡是"成功/失败"类型的数据，都能用似然函数反推背后的概率 θ：

| 例子 | 观察到的数据 | 想反推的 θ |
|------|------------|-----------|
| 硬币公不公平 | 73/100次正面 | 硬币偏差程度 |
| 新药有没有用 | 82/100人康复 | 药物真实治愈率 |
| 工厂产品合格率 | 3/50个缺陷 | 生产线缺陷率 |
| 游戏付费概率 | 150/1000人付费 | 用户付费概率 |

### 计算例子

抛5次硬币，3次正面2次反面：

$$\mathcal{L}(\theta) = \theta^3(1-\theta)^2$$

取对数求导，令导数=0：

$$\frac{d}{d\theta}\ln\mathcal{L} = \frac{3}{\theta} - \frac{2}{1-\theta} = 0 \implies \theta = \frac{3}{5} = 0.6$$

> 最大似然估计 = 正面次数 ÷ 总次数，非常直觉！

### 似然最大 ≠ θ最可能

| 方法 | 公式 | 含义 |
|------|------|------|
| 最大似然MLE | $\max \mathcal{L}(\theta)$ | 只看数据，忽略先验 |
| 最大后验MAP | $\max \mathcal{L}(\theta) \times p(\theta)$ | 数据+先验一起考虑 |

> 数据越多，两者越接近。数据很少时，先验非常重要。

## 2. Beta-二项模型

### 2.1 似然

**场景：** 抛硬币，θ = 正面朝上的概率

观察计数 $D = (N_1, N)$，使用二项分布：

$$\text{Bin}(N_1|N,\theta) = \binom{N}{N_1}\theta^{N_1}(1-\theta)^{N-N_1}$$

**关键点：** $\binom{N}{N_1}$ 与 θ 无关，可以忽略，所以：

$$\mathcal{L}(\theta) \propto \theta^{N_1}(1-\theta)^{N_0}$$

**充分统计量：** 只需要知道 $N_1$（正面次数）和 $N$（总次数），顺序信息对估计 θ 没有额外贡献。

### 2.2 先验

**为什么需要先验？**

贝叶斯方法要求在看数据之前，对 θ 有一个初始"感觉"——这就是先验分布 $p(\theta)$。

**为什么选Beta分布？**

让先验和似然形式一样，相乘之后形式不变，计算简单：

$$\text{Beta}(\theta|a,b) \propto \theta^{a-1}(1-\theta)^{b-1}$$

**超参数 a, b 的含义：**

> $a$ = 虚构的正面次数（+1）
> $b$ = 虚构的反面次数（+1）

| 先验 | 含义 |
|------|------|
| Beta(1,1) | 完全不知道，均匀分布 |
| Beta(10,2) | 认为硬币偏向正面 |
| Beta(100,100) | 非常确信是公平硬币 |

**为什么指数是 a-1 而不是 a？**

纯粹是数学定义习惯，让均值公式更简洁：$\mu = \frac{a}{a+b}$

### 2.3 后验

$$\underbrace{\text{Beta}(a,b)}_{\text{先验}} + \underbrace{N_1\text{次正面，}N_0\text{次反面}}_{\text{数据}} \longrightarrow \underbrace{\text{Beta}(a+N_1,\ b+N_0)}_{\text{后验}}$$

**伪计数（Pseudo Counts）：** a 和 b 就像"虚构的历史数据"，观测数据直接叠加。

**等效样本量：** $\alpha_0 = a + b$，先验强度类比于数据量 $N$。

**披萨店例子：**
- 先验：Beta(2,2)，对好评率不确定
- 数据：10个顾客，8好评2差评
- 后验：Beta(10,4)
- 后验均值：$\frac{10}{14} \approx 0.71$，好评率约71%

**先验强弱的影响：**

| 先验 | α₀ | 后验（8好评2差评） | 后验均值 |
|------|-----|-----------------|---------|
| Beta(1,1) | 2 | Beta(9,3) | 0.75 |
| Beta(2,2) | 4 | Beta(10,4) | 0.71 |
| Beta(10,10) | 20 | Beta(18,12) | 0.60 |
| Beta(50,50) | 100 | Beta(58,52) | 0.53 |

### 2.4 后验预测分布

**目标：** 不估计θ，直接预测下一次观测结果。

$$p(\tilde{x}=1|D) = \int_0^1 \theta \cdot p(\theta|D) \, d\theta = E_{p(\theta|D)}[\theta] = \frac{N_1+a}{N_1+N_0+a+b}$$

**和MLE预测的对比：**

| 方法 | 预测公式 | 问题 |
|------|---------|------|
| 最大似然 | $\frac{N_1}{N}$ | 数据少时不稳定 |
| 后验预测 | $\frac{N_1+a}{N+a+b}$ | 有先验保底，更稳健 |

**极端例子：** 抛1次得正面
- MLE：100%正面（离谱！）
- 后验预测 Beta(2,2)：3/5 = 60%（合理）

## 3. 过拟合与黑天鹅悖论

### 零计数问题

抛3次硬币，全是反面：

$$\hat{\theta}_{MLE} = \frac{0}{3} = 0$$

MLE认为正面**永远不可能**出现——显然错误！

### 黑天鹅悖论

> 17世纪欧洲人只见过白天鹅，认为黑天鹅不存在。1697年在澳大利亚发现了黑天鹅。

**没见过 ≠ 不可能**

即使在大数据时代，细分数据后每个子群体可能数据极少：
```
年龄40-45岁 + 男性 + 高血压 + 糖尿病 + 住在巴塞尔
→ 可能只有3个病人！零计数照样出现。
```

### 贝叶斯解法：拉普拉斯继承法则

用均匀先验 Beta(1,1)，即 a=b=1：

$$p(\tilde{x}=1|D) = \frac{N_1+1}{N_1+N_0+2}$$

**效果：**

| 数据 | MLE | 拉普拉斯 |
|------|-----|---------|
| 0正3反 | 0% | 20% |
| 0正30反 | 0% | 3.1% |
| 80正20反 | 80% | 79.6% |

> 数据越多，+1的影响越小，最终收敛到MLE。

## 4. 常见连续分布：Beta分布

### 完整公式

$$p(x|\alpha,\beta) = \frac{1}{B(\alpha,\beta)} x^{\alpha-1}(1-x)^{\beta-1}, \quad x \in [0,1]$$

- $B(\alpha,\beta)$：归一化常数，让分布积分=1，考试基本不用管
- 均值：$\mu = \frac{\alpha}{\alpha+\beta}$

### 不同参数的形状

```
Beta(1,1)：平的（均匀分布，啥都不知道）
Beta(2,2)：温和的山（稍微倾向0.5）
Beta(10,10)：很尖的山（非常确信θ=0.5）
Beta(8,2)：偏右（认为θ偏大）
```

## 5. Dirichlet-多项模型

### 为什么需要它？

Beta-二项模型只处理**两种结果**（硬币），现实中很多问题有**多种结果**：
- 用户点击广告：购买/加购/点击/忽略
- 邮件分类：工作/垃圾/促销/私人
- 骰子：6种结果

### 5.1 多项分布

二项分布的K种结果推广：

$$p(D|\theta) \propto \prod_{k=1}^{K} \theta_k^{N_k} = \theta_1^{N_1} \times \theta_2^{N_2} \times \cdots \times \theta_K^{N_K}$$

多项式系数（排列数）：

$$\frac{n!}{x_1! x_2! \cdots x_K!}$$

**理解：** 分子是所有排列，分母是把"同一面多次出现互换"产生的重复去掉。

**特殊情况：** n=1时叫Categorical分布（类别分布），就是"第j面的概率是θⱼ"。

### 5.2 Dirichlet分布

Beta分布的K维推广，定义在**概率单纯形**上：

$$\text{Dir}(\theta|\alpha) = \frac{1}{B(\alpha)}\prod_{k=1}^K \theta_k^{\alpha_k-1}$$

**约束条件（概率单纯形）：**
$$\sum_{k=1}^K \theta_k = 1, \quad \theta_k \geq 0$$

K=3时是一个三角形，三个顶点分别代表100%确定是某一类。

**均值：**
$$E[\theta_k] = \frac{\alpha_k}{\sum_j \alpha_j}$$

**超参数含义：**

| 先验 | 含义 |
|------|------|
| Dir(1,1,...,1) | 完全不知道，均匀先验 |
| 所有αk相等且很大 | 强烈认为各面概率相等 |
| 某个αk很大 | 强烈认为第k面概率高 |

### 5.3 后验推导

$$p(\theta|D) \propto \underbrace{\prod_{k=1}^K \theta_k^{N_k}}_{\text{似然}} \times \underbrace{\prod_{k=1}^K \theta_k^{\alpha_k-1}}_{\text{先验}} = \prod_{k=1}^K \theta_k^{N_k+\alpha_k-1} = \text{Dir}(\theta|\alpha_1+N_1,...,\alpha_K+N_K)$$

**更新规则：**
$$\text{Dir}(\alpha_1,...,\alpha_K) \xrightarrow{\text{观测}(N_1,...,N_K)} \text{Dir}(\alpha_1+N_1,...,\alpha_K+N_K)$$

直接把观测次数加到超参数上！

**奶茶店例子：**
- 先验：Dir(2,2,2)
- 数据：珍珠50杯，抹茶30杯，草莓20杯
- 后验：Dir(52,32,22)
- 后验均值：θ₁≈0.49，θ₂≈0.30，θ₃≈0.21

### 5.4 后验预测分布

$$p(\tilde{X}=j|D) = \int \theta_j \cdot p(\theta_j|D) \, d\theta_j = E[\theta_j] = \frac{N_j+\alpha_j}{\sum_k(N_k+\alpha_k)}$$

**考试推导三步：**
1. 写出积分 $\int p(\tilde{X}=j|\theta)p(\theta|D)d\theta$
2. $p(\tilde{X}=j|\theta) = \theta_j$，化简成期望
3. 代入Dirichlet均值公式

**贝叶斯平滑的作用：** 分母加了 $\sum_k\alpha_k$，保证没见过的类别概率永远不为零。

## 6. 语言模型与N-gram

### 6.1 什么是语言模型

> **给定前面的词，预测下一个词是什么。**

正式定义：

$$P(x^{(t+1)} | x^{(t)}, x^{(t-1)}, ..., x^{(1)})$$

现实应用：手机输入法、搜索自动补全、邮件补全、ChatGPT（本质上都是在预测下一个词）

### 6.2 N-gram模型

**核心假设：** 预测下一个词，只需要看前面 n-1 个词。

| 模型 | 假设 | 公式 |
|------|------|------|
| 1-gram | 每个词独立 | $P(x^{(t+1)})$ |
| 2-gram | 只看前1个词 | $P(x^{(t+1)}\|x^{(t)})$ |
| 3-gram | 只看前2个词 | $P(x^{(t+1)}\|x^{(t)}, x^{(t-1)})$ |

**句子例子：** "the students opened their books"

```
3-gram：
(the, students, opened)
(students, opened, their)
(opened, their, books)
```

**N越大越好吗？**

| N | 优点 | 缺点 |
|---|------|------|
| 小（1,2） | 数据够用，零计数少 | 上下文太短，预测不准 |
| 大（4,5） | 上下文丰富，预测准 | 数据稀疏，零计数问题严重 |

### 6.3 Mono-gram模型

**核心类比：** 预测下一个词 = 扔一个"词汇骰子"

| 骰子问题 | 语言模型 |
|---------|---------|
| K面骰子 | V个词的词汇表 |
| 第k面朝上 | 第k个词出现 |
| 每面概率θk | 每个词的概率Pk |

**完整贝叶斯流程：**

1. **先验：** Dir(1,1,...,1)，所有词地位相等
2. **数据：** 统计每个词在语料库中出现的次数
3. **后验：** Dir(α₁+N₁, α₂+N₂, ..., αV+NV)
4. **预测：** $P(\tilde{x}=\text{word}_j|D) = \frac{N_j+\alpha_j}{\sum_k(N_k+\alpha_k)}$

**零计数问题：**

| 词 | 出现次数 | MLE概率 | 贝叶斯概率 |
|----|---------|---------|-----------|
| the | 5000次 | 0.10 | ≈0.10 |
| books | 100次 | 0.002 | ≈0.002 |
| serendipity | 0次 | **0%！** | **>0% ✅** |

### 6.4 构建3-gram模型（代码）

**两步走：**

**第一步：统计共现次数**
```python
for sentence in reuters.sents():
    for w1, w2, w3 in trigrams(sentence, pad_right=True):
        model[(w1, w2)][w3] += 1
```

统计结果示例：
```
model["opened"]["their"]["books"]   = 100
model["opened"]["their"]["laptops"] = 80
model["opened"]["their"]["eyes"]    = 30
```

**第二步：转成概率（MLE）**
```python
for w1, w2 in model:
    total_count = float(sum(model[w1,w2].values()))
    for w3 in model[w1,w2]:
        model[w1,w2][w3] /= total_count
```

$$P(w_3|w_1,w_2) = \frac{\text{count}(w_1,w_2,w_3)}{\text{count}(w_1,w_2)}$$

**贝叶斯平滑版本（解决零计数）：**

$$P(w_3|w_1,w_2) = \frac{\text{count}(w_1,w_2,w_3)+\alpha}{\text{count}(w_1,w_2)+\alpha \times V}$$

## 总结：整体知识框架

```
硬币问题（2种结果）
  ├── 似然：Binomial
  ├── 先验：Beta(a,b)
  ├── 后验：Beta(a+N₁, b+N₀)
  └── 后验预测：(N₁+a)/(N+a+b)
          ↓ 推广到K种结果
骰子问题（K种结果）
  ├── 似然：Multinomial
  ├── 先验：Dirichlet(α)
  ├── 后验：Dirichlet(α+N)
  └── 后验预测：(Nj+αj)/Σ(Nk+αk)
          ↓ 应用到语言
语言模型
  ├── 词汇表 = 超大骰子
  ├── N-gram = 只看前n-1个词
  ├── 贝叶斯平滑 = 解决零计数问题
  └── 后验预测 = 预测下一个词
```

## 考试重点公式速查

| 名称 | 公式 |
|------|------|
| Beta分布 | $\text{Beta}(\theta\|a,b) \propto \theta^{a-1}(1-\theta)^{b-1}$ |
| Beta均值 | $\mu = \frac{a}{a+b}$ |
| Beta后验更新 | $\text{Beta}(a,b) \to \text{Beta}(a+N_1, b+N_0)$ |
| 二项后验预测 | $\frac{N_1+a}{N+a+b}$ |
| Dirichlet分布 | $\text{Dir}(\theta\|\alpha) \propto \prod_k \theta_k^{\alpha_k-1}$ |
| Dirichlet均值 | $E[\theta_k] = \frac{\alpha_k}{\sum_j \alpha_j}$ |
| Dirichlet后验更新 | $\text{Dir}(\alpha) \to \text{Dir}(\alpha_k+N_k)$ |
| 多项后验预测 | $\frac{N_j+\alpha_j}{\sum_k(N_k+\alpha_k)}$ |
| 拉普拉斯法则 | $\frac{N_1+1}{N_1+N_0+2}$ |
