# 贝叶斯与机器学习硬核计算题复习精选

## 题型一：拉普拉斯近似（Laplace's Approximation）计算题

### 📝 题目背景
假设某项科学实验中，我们得到了一个未归一化的后验概率密度函数：
$$p^*(\theta) = \theta e^{-2\theta}$$
其中参数 $\theta > 0$。我们想要利用**拉普拉斯近似**，将这个奇形怪状的函数近似为一个标准的**高斯（正态）分布** $\mathcal{N}(\mu, \sigma^2)$。

**请计算出：**
1. 高斯分布的均值 $\mu$（即寻找山顶 $\hat{\theta}$）。
2. 高斯分布的方差 $\sigma^2$（即计算山顶的陡峭度 $c$）。

---

### ✍️ 详细解题步骤（人话版）

#### 第一步：把世界“对数化”，好爬山
拉普拉斯教我们的第一步是先对原函数取对数 $\ln$，把乘法和指数变成好算、好求导的加减法：
$$\ln p^*(\theta) = \ln(\theta e^{-2\theta}) = \ln\theta + \ln(e^{-2\theta}) = \ln\theta - 2\theta$$

#### 第二步：求一阶导数，寻找山顶 $\hat{\theta}$（均值 $\mu$）
山顶的切线是平的，所以一阶导数一定等于 0。我们对上面的方程关于 $\theta$ 求一阶导数：
$$\frac{d}{d\theta}[\ln p^*(\theta)] = \frac{1}{\theta} - 2$$
让它等于 0 算出山顶位置：
$$\frac{1}{\theta} - 2 = 0 \implies \hat{\theta} = \frac{1}{2} = 0.5$$

**【阶段结论 1】** 我们的高斯帽子应该扣在 $\theta = 0.5$ 的位置。所以，近似高斯分布的**均值 $\mu = 0.5$**。

#### 第三步：求二阶导数，量量山顶有多陡（算出 $c$ 与方差）
我们对一阶导数结果 $\frac{1}{\theta} - 2$ 再求一次导数（二阶导数）：
$$\frac{d^2}{d\theta^2}[\ln p^*(\theta)] = -\frac{1}{\theta^2}$$
现在，把我们刚才算出来的山顶位置 $\hat{\theta} = 0.5$ 代入进去，看看这个地方到底有多弯曲：
$$\text{在山顶处的二阶导数} = -\frac{1}{(0.5)^2} = -\frac{1}{0.25} = -4$$
根据拉普拉斯公式，陡峭度系数 $c$ 是二阶导数加个负号（让它变成正数）：
$$c = -(-4) = 4$$

#### 第四步：把陡峭度转化为标准高斯分布的方差 $\sigma^2$
在数学上，高斯分布的二次项系数是 $-\frac{1}{2\sigma^2}$，而拉普拉斯展开的二次项系数是 $-\frac{c}{2}$。它们俩是完美的平替关系！
所以：
$$-\frac{c}{2} = -\frac{1}{2\sigma^2} \implies c = \frac{1}{\sigma^2} \implies \sigma^2 = \frac{1}{c}$$
既然我们算出了 $c = 4$，那么方差就是：
$$\sigma^2 = \frac{1}{4} = 0.25$$

### 🎯 最终标答
通过拉普拉斯近似，这个原本扭曲的函数 $p^*(\theta) = \theta e^{-2\theta}$，被我们成功拍扁并强行伪装成了一个**均值为 0.5、方差为 0.25 的标准正态分布 $\mathcal{N}(0.5, 0.25)$**！

## 题型二：决策边界超平面与几何距离计算题

### 📝 题目背景
在一个二维的特征空间里，我们训练出了一个线性分类器，它的判别方程（决策超平面）为：
$$g(x) = 3x_1 + 4x_2 - 12 = 0$$
现在，测试集里来了两个新样本点：
* 样本点 $A = (4, 2)$
* 样本点 $B = (1, 1)$

**请计算并回答：**
1. 这根决策直线的法向量 $w$ 的模长 $\|w\|$ 是多少？
2. 样本点 $A$ 和 样本点 $B$ 距离这根决策直线的**真实物理距离 $r$** 各是多少？它们分别属于哪个阵营？

---

### ✍️ 详细解题步骤（人话版）

#### 第一步：提炼出公式的“法向量”和偏置
把方程 $g(x) = 3x_1 + 4x_2 - 12$ 对照标准公式 $g(x) = w^T x + w_0$：
* 参数权重向量（法向量）为：$$w = \begin{pmatrix} 3 \\ 4 \end{pmatrix}$$
* 偏置为：$w_0 = -12$

根据勾股定理，算出这个法向量的物理模长（长度）：
$$\|w\| = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$

**【阶段结论 1】** 法向量的模长 $\|w\| = 5$。这也就是我们的“距离放大器”。

#### 第二步：把样本点代入方程，算“无符号账”

##### 🟢 对于样本点 $A(4, 2)$：
直接把坐标代入判别方程，看看电脑会算出个什么数字：
$$g(A) = 3(4) + 4(2) - 12 = 12 + 8 - 12 = +8$$
* **认领阵营：** 因为算出来的数字 $+8 > 0$，说明点 $A$ 落在**正派那一侧（Positive Side）**。
* **计算真实物理距离 $r_A$：** 用人话公式 `物理距离 = 算出的数字 ÷ 向量模长`：
  $$r_A = \frac{g(A)}{\|w\|} = \frac{8}{5} = 1.6$$

##### 🔴 对于样本点 $B(1, 1)$：
同样，把坐标代入判别方程：
$$g(B) = 3(1) + 4(1) - 12 = 3 + 4 - 12 = -5$$
* **认领阵营：** 因为算出来的数字 $-5 < 0$，说明点 $B$ 落在**反派那一侧（Negative Side）**。
* **计算真实物理距离 $r_B$：** $$r_B = \frac{g(B)}{\|w\|} = \frac{-5}{5} = -1$$
  （负号在几何上只代表方向在反面，拿尺子量出来的绝对物理距离就是 1）。

### 🎯 最终标答
1. 法向量模长 $\|w\| = 5$。
2. 样本点 $A$ 属于**正类**，距离决策面的真实物理距离是 **1.6**。
3. 样本点 $B$ 属于**负类**，距离决策面的真实物理距离是 **1**。
4. 因为 $|g(A)| = 8 > |g(B)| = 5$，说明点 $A$ 离分界线更远，模型对分类点 $A$ 的决策**更有信心（确信度更高）**！



# 贝叶斯预测与边际似然硬核计算题

## 题型一：贝叶斯预测分布（Predictive Distribution）计算题

### 📝 题目背景
假设我们要预测一个新网页的点击率。已知新用户点击网页只有两种可能：点击（$y=1$）或 不点击（$y=0$）。
网页的真实点击率由参数 $w$ 决定（即 $P(y=1 \mid w) = w$）。
根据历史数据，我们对参数 $w$ 的可能取值及其靠谱程度（后验概率）整理如下：
* 专家 A 认为点击率 $w_1 = 0.1$，该意见的靠谱程度为 $P(w_1 \mid \mathcal{D}) = 0.2$
* 专家 B 认为点击率 $w_2 = 0.5$，该意见的靠谱程度为 $P(w_2 \mid \mathcal{D}) = 0.5$
* 专家 C 认为点击率 $w_3 = 0.8$，该意见的靠谱程度为 $P(w_3 \mid \mathcal{D}) = 0.3$

**请计算：**
下一个新用户访问时，点击网页的**贝叶斯预测概率 $P(y=1 \mid \mathcal{D})$** 是多少？

---

### ✍️ 详细解题步骤（人话版）

#### 第一步：理解公式背后的“全员投票”
贝叶斯预测公式的离散版本为：
$$P(y=1 \mid \mathcal{D}) = \sum_{i=1}^3 P(y=1 \mid w_i) P(w_i \mid \mathcal{D})$$
人话翻译就是：让这 3 个专家轮流出来预测，每个人投出自己的预测值 $P(y=1 \mid w_i)$，然后乘以他们手里握着的选票权重 $P(w_i \mid \mathcal{D})$，最后全部加起来算总分。

#### 第二步：列出每位专家的“加权贡献”
* **专家 A 的贡献：** 预测点击概率为 $0.1$，其选票权重为 $0.2$。加权得分：$0.1 \times 0.2 = 0.02$
* **专家 B 的贡献：** 预测点击概率为 $0.5$，其选票权重为 $0.5$。加权得分：$0.5 \times 0.5 = 0.25$
* **专家 C 的贡献：** 预测点击概率为 $0.8$，其选票权重为 $0.3$。加权得分：$0.8 \times 0.3 = 0.24$

#### 第三步：全员选票汇总
把所有专家的加权预测结果相加（等价于连续变量里的积分动作）：
$$P(y=1 \mid \mathcal{D}) = 0.02 + 0.25 + 0.24 = 0.51$$

### 🎯 最终标答
综合听取了全社会（所有专家）的意见后，贝叶斯回归对下一个新用户点击网页的预测概率为 **$0.51$**。

## 题型二：边际似然（Marginal Likelihood）与模型选择计算题

### 📝 题目背景
我们要在一枚硬币上玩丢硬币游戏，收集到的数据为 $\mathcal{D} = \{\text{正面}, \text{正面}\}$（连续两次正面）。现在有两个互相对立的模型家族想要解释这个现象：

1. **简单模型家族 ($\mathcal{F}_1$)**：认为硬币绝对公平。它没有多余的参数，其参数空间只有一个死板的成员：正面概率 $w = 0.5$。
2. **复杂模型家族 ($\mathcal{F}_2$)**：认为硬币可能被动过手脚。它非常灵活，其参数空间包含 3 个等概率出现的可能成员：$w \in \{0.1, 0.5, 0.9\}$（即先验概率 $P(w \mid \mathcal{F}_2) = \frac{1}{3}$）。

**请计算并回答：**
1. 简单模型家族 $\mathcal{F}_1$ 的边际似然分数 $P(\mathcal{D} \mid \mathcal{F}_1)$ 是多少？
2. 复杂模型家族 $\mathcal{F}_2$ 的边际似然分数 $P(\mathcal{D} \mid \mathcal{F}_2)$ 是多少？
3. 根据贝叶斯模型选择，我们应该挑选哪个模型家族？为什么？

---

### ✍️ 详细解题步骤（人话版）

#### 第一步：计算简单家族 $\mathcal{F}_1$ 的全队分数
因为 $\mathcal{F}_1$ 家族只有一个成员 $w = 0.5$，它的全队平均分就是这个成员的表现。
连续两次正面的概率（似然值）为：
$$P(\mathcal{D} \mid \mathcal{F}_1) = 0.5 \times 0.5 = \mathbf{0.25}$$

#### 第二步：计算复杂家族 $\mathcal{F}_2$ 的“全队平均分”
复杂家族 $\mathcal{F}_2$ 有 3 个成员，贝叶斯边际似然要求我们计算这 3 个成员的**平均拟合表现**。
离散版本的边际似然公式为：
$$P(\mathcal{D} \mid \mathcal{F}_2) = \sum_{j=1}^3 P(\mathcal{D} \mid w_j, \mathcal{F}_2) P(w_j \mid \mathcal{F}_2)$$

我们先算各个成员在看到“两次正面”数据时的个人得分（似然值）：
* 成员 1 ($w=0.1$)：得分 $0.1 \times 0.1 = 0.01$
* 成员 2 ($w=0.5$)：得分 $0.5 \times 0.5 = 0.25$ （这是该家族里的特种兵）
* 成员 3 ($w=0.9$)：得分 $0.9 \times 0.9 = 0.81$

现在，因为每个人的先验权重都是 $\frac{1}{3}$，我们把全队的分数加起来求平均：
$$P(\mathcal{D} \mid \mathcal{F}_2) = (0.01 \times \frac{1}{3}) + (0.25 \times \frac{1}{3}) + (0.81 \times \frac{1}{3})$$
$$P(\mathcal{D} \mid \mathcal{F}_2) = \frac{0.01 + 0.25 + 0.81}{3} = \frac{1.07}{3} \approx \mathbf{0.3567}$$

#### 第三步：同台竞技，做出选择
对比两个家族的最终综合得分（边际似然）：
* $P(\mathcal{D} \mid \mathcal{F}_1) = 0.25$
* $P(\mathcal{D} \mid \mathcal{F}_2) \approx 0.3567$

由于 $0.3567 > 0.25$，复杂模型家族 $\mathcal{F}_2$ 的边际似然分数更高。

#### 💡 灵魂思考：为什么这次复杂模型赢了？奥卡姆剃刀失效了吗？
没有失效！因为目前的数据是“连续两次正面”，这是一个明显的偏向信号。复杂家族虽然包含了 $w=0.1$ 这样的超级猪队友（得分仅为 0.01），但它同样包含了一个极度契合该数据的天才成员 $w=0.9$（得分高达 0.81）。这个天才拉高了全队的平均分，使得复杂家族的综合表现超越了保守的简单家族。

如果数据变成“一次正面一次反面”，简单家族就会凭借毫无猪队友的稳定性给复杂家族上一课！

### 🎯 最终标答
1. 简单家族的边际似然为 $0.25$。
2. 复杂家族的边际似然约为 $0.3567$。
3. 应当选择**复杂模型家族 $\mathcal{F}_2$**，因为它的全队平均边际似然分数更高，对当前倾斜的数据拥有更好的综合解释能力。


# 贝叶斯连续积分硬核计算题

## 题型一：连续型贝叶斯预测分布（Predictive Distribution）计算题

### 📝 题目背景
假设我们正在观测一台高精度传感器。已知传感器输出的连续型测量值 $y$ 服从一个均值为 $w$、方差为 $1$ 的高斯分布，即条件似然（Likelihood）为：
$$p(y \mid w) = \frac{1}{\sqrt{2\pi}} e^{-\frac{1}{2}(y - w)^2}$$
我们通过先验知识或者历史数据，得知参数 $w$ 本身也是一个连续的随机变量，且其后验概率分布（Posterior）刚好服从一个均值为 $0$、方差为 $1$ 的标准正态分布：
$$p(w \mid \mathcal{D}) = \frac{1}{\sqrt{2\pi}} e^{-\frac{1}{2}w^2}$$

**请计算：**
在考虑了参数 $w$ 的所有不确定性后，新观测值 $y$ 的**贝叶斯预测分布 $p(y \mid \mathcal{D})$** 表达式（提示：通过积分将 $w$ 消除）。

---

### ✍️ 详细解题步骤

#### 第一步：列出全员投票的连续积分公式
根据贝叶斯全概率预测公式，我们需要对参数 $w$ 在整个实数空间 $(-\infty, +\infty)$ 上进行加权积分：
$$p(y \mid \mathcal{D}) = \int_{-\infty}^{+\infty} p(y \mid w) p(w \mid \mathcal{D}) \, dw$$
我们将两个高斯分布的表达式代入其中：
$$p(y \mid \mathcal{D}) = \int_{-\infty}^{+\infty} \left( \frac{1}{\sqrt{2\pi}} e^{-\frac{1}{2}(y - w)^2} \right) \left( \frac{1}{\sqrt{2\pi}} e^{-\frac{1}{2}w^2} \right) \, dw$$
把常数项提到积分符号外面，并将指数部分相加合并：
$$p(y \mid \mathcal{D}) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} e^{-\frac{1}{2} \left[ (y - w)^2 + w^2 \right]} \, dw$$

#### 第二步：配方思想（Squares Completion）
为了积掉 $w$，我们需要把指数里关于 $w$ 的二次多项式强行配方。先展开括号内的式子：
$$(y - w)^2 + w^2 = y^2 - 2yw + w^2 + w^2 = 2w^2 - 2yw + y^2$$
现在我们要凑出关于 $w$ 的完全平方式，提取出系数 $2$：
$$2w^2 - 2yw + y^2 = 2\left( w^2 - yw \right) + y^2 = 2\left( w - \frac{y}{2} \right)^2 - 2\left(\frac{y}{2}\right)^2 + y^2$$
进一步化简：
$$2\left( w - \frac{y}{2} \right)^2 - \frac{y^2}{2} + y^2 = 2\left( w - \frac{y}{2} \right)^2 + \frac{y^2}{2}$$
把这个重新配方后的结果塞回积分的指数项中：
$$p(y \mid \mathcal{D}) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} e^{-\frac{1}{2} \left[ 2\left( w - \frac{y}{2} \right)^2 + \frac{y^2}{2} \right]} \, dw$$
由于 $\frac{y^2}{2}$ 项与积分变量 $w$ 毫无关系，它对于积分来说是一个常数，可以提到积分号外面：
$$p(y \mid \mathcal{D}) = \frac{1}{2\pi} e^{-\frac{1}{4}y^2} \int_{-\infty}^{+\infty} e^{-\left( w - \frac{y}{2} \right)^2} \, dw$$

#### 第三步：利用高斯积分常数求解
注意观察积分号内部：$\int_{-\infty}^{+\infty} e^{-\left( w - \frac{y}{2} \right)^2} \, dw$。
这是一个标准的标准概率密度函数积分变形。根据大名鼎鼎的高斯积分公式 $\int_{-\infty}^{+\infty} e^{-ax^2} dx = \sqrt{\frac{\pi}{a}}$（这里 $a=1$，自变量平移不影响积分结果），我们直接得出：
$$\int_{-\infty}^{+\infty} e^{-\left( w - \frac{y}{2} \right)^2} \, dw = \sqrt{\pi}$$
将这个积分结果代回原式：
$$p(y \mid \mathcal{D}) = \frac{1}{2\pi} e^{-\frac{1}{4}y^2} \cdot \sqrt{\pi} = \frac{1}{\sqrt{4\pi}} e^{-\frac{1}{4}y^2}$$
为了看清它的本质，我们将其改写为标准高斯分布 $\frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(y-\mu)^2}{2\sigma^2}}$ 的对齐形式：
$$p(y \mid \mathcal{D}) = \frac{1}{\sqrt{2\pi \cdot 2}} e^{-\frac{y^2}{2 \cdot 2}}$$

### 🎯 最终标答
通过连续积分消去 $w$ 之后，我们发现新观测值 $y$ 的贝叶斯预测分布依然是一个完美的正态分布，其**均值为 $0$，方差为 $2$（即 $p(y \mid \mathcal{D}) \sim \mathcal{N}(0, 2)$）**。
* **人话直觉：** 似然贡献了 $1$ 的不确定性（方差），先验贡献了 $1$ 的不确定性（方差），两股不确定性加权融合后，最终的预测不确定性变成了 $1 + 1 = 2$。

## 题型二：连续型边际似然（Marginal Likelihood）计算题

### 📝 题目背景
假设我们观测到了一个单一的数据点 $\mathcal{D} = \{y\}$。我们提出了一个连续型的线性模型家族来解释它。
已知该模型的条件似然（数据生成的概率）为均匀分布（Uniform Distribution）：
$$p(y \mid w) = \begin{cases} \frac{1}{w} & 0 \le y \le w \\ 0 & \text{其他} \end{cases}$$
也就是说，参数 $w$ 决定了数据能产生的最大上限。而参数 $w$ 本身的连续型先验分布也是一个均匀分布，范围在 $0$ 到 $1$ 之间：
$$p(w) = \begin{cases} 1 & 0 \le w \le 1 \\ 0 & \text{其他} \end{cases}$$

**请计算：**
该模型家族产生这一观测数据 $y$ 的**连续型边际似然分数 $p(y)$**（其中 $0 < y < 1$）。

---

### ✍️ 详细解题步骤

#### 第一步：明确积分边界的“隐形大坑”
边际似然的连续公式为：
$$p(y) = \int_{-\infty}^{+\infty} p(y \mid w) p(w) \, dw$$
这里有个极容易扣分的考点——**确定积分的有效上下限**：
1. 先验分布要求：$0 \le w \le 1$
2. 条件似然要求：$0 \le y \le w \implies w \ge y$
将这两个条件取交集，我们发现参数 $w$ 的有效取值范围并不是全局，而是被死死限制在 **$w \in [y, 1]$** 之间。

#### 第二步：列出积分式并求解
将两个分布的代码带入对应的有效区间内：
$$p(y) = \int_{y}^{1} \left( \frac{1}{w} \right) \cdot (1) \, dw = \int_{y}^{1} \frac{1}{w} \, dw$$
这是一个非常基础的初等函数积分。我们知道 $\frac{1}{w}$ 的原函数是 $\ln|w|$：
$$p(y) = \Big[ \ln|w| \Big]_{y}^{1} = \ln(1) - \ln(y)$$
因为 $\ln(1) = 0$，所以：
$$p(y) = 0 - \ln(y) = -\ln(y)$$

### 🎯 最终标答
该连续模型家族的边际似然分数为 **$p(y) = -\ln(y)$** （由于 $0 < y < 1$，$\ln(y)$ 是负数，因此 $-\ln(y)$ 整体是一个正数分数）。
* **人话直觉：** 观测到的数字 $y$ 越小（比如 $y = 0.01$），$-\ln(0.01)$ 算出来的边际似然得分就越高。这是因为较小的 $y$ 能够完美包容更多的 $w$ 参数空间（因为要求 $w \ge y$），全队的平均通过率被拉高了。


# 广义线性判别函数（Generalized Linear Discriminant Functions）硬核计算题

## 📝 题目背景
在一个一维的特征空间中（数据只有 $x$ 一个维度），我们有两类数据点：
* 正类点（$c_1$）：$x = 0$
* 负类点（$c_2$）：$x = -2$ 和 $x = 2$

显然，在一维的数轴上，你无法只画一个点（一维的决策边界就是一个点）把中间的 $0$ 和两边的 $-2, 2$ 分开。

我们现在引入一组广义基函数，将数据映射到二维空间：
* $b_1(x) = x$
* $b_2(x) = x^2$

已知经过训练后，新空间里的判别超平面参数权重为：$w_0 = 2, w_1 = 0, w_2 = -1$。也就是说，广义判别方程为：
$$g(x) = 2 + 0 \cdot b_1(x) - 1 \cdot b_2(x) = 2 - x^2$$

**请计算并回答：**
1. 原始点 $x = 0$ 和 $x = 2$ 映射到新二维空间后的坐标 $y = (b_1(x), b_2(x))$ 各是多少？
2. 利用判别方程 $g(x)$，对 $x = 0$ 和 $x = 2$ 进行分类决策（判断它们属于正类还是负类）。
3. 这个分类器在原始一维空间里的**真实决策边界**是什么形状？（提示：令 $g(x) = 0$）

---

### ✍️ 详细解题步骤（人话版）

#### 第一步：空间穿梭！算一算新空间里的坐标
我们把原始的一维数字 $x$ 代入到基函数 $b_1(x)=x$ 和 $b_2(x)=x^2$ 中，变成二维坐标 $(y_1, y_2)$：
* **对于 $x = 0$：**
  $b_1(0) = 0$
  $b_2(0) = 0^2 = 0$
  新坐标为：$y_{x=0} = (0, 0)$
* **对于 $x = 2$：**
  $b_1(2) = 2$
  $b_2(2) = 2^2 = 4$
  新坐标为：$y_{x=2} = (2, 4)$

#### 第二步：代入判别方程，贴标签
我们将点代入广义判别方程 $g(x) = 2 - x^2$：
* **对于 $x = 0$：**
  $$g(0) = 2 - 0^2 = +2$$
  因为算出来的数字 $+2 > 0$，所以模型判定 $x = 0$ 属于**正类（$c_1$）**。
* **对于 $x = 2$：**
  $$g(2) = 2 - 2^2 = 2 - 4 = -2$$
  因为算出来的数字 $-2 < 0$，所以模型判定 $x = 2$ 属于**负类（$c_2$）**。

#### 第三步：破案！看看在原始空间里画出了什么边界
我们让判别方程等于 $0$，来看看真正的国界线划在哪里：
$$g(x) = 2 - x^2 = 0 \implies x^2 = 2 \implies x = \pm\sqrt{2} \approx \pm 1.414$$

### 🎯 最终标答
1. 映射后的新空间坐标分别为：$y_{x=0} = (0, 0)$， $y_{x=2} = (2, 4)$。
2. 决策分类结果：$x=0$ 为**正类**，$x=2$ 为**负类**。
3. 在原始一维数轴上，该分类器的真实决策边界是**两个对称的点 $x = \sqrt{2}$ 和 $x = -\sqrt{2}$**。这两个点构成的“夹击圈”，完美地把中间的 $0$ 保护在正类阵营，把外面大本营的 $-2$ 和 $2$ 划归为负类。

# 线性可分与负规范化（Separable Case）硬核计算题

## 📝 题目背景
在经过增广特征表示后（已经把偏置项融入了向量），我们手里有 3 个属于两个不同阵营的二维数据点：
* 属于类 1（$c_1$）的样本：$y_1 = \begin{pmatrix} 1 \\ 2 \end{pmatrix}$
* 属于类 2（$c_2$）的样本：$y_2 = \begin{pmatrix} -1 \\ 1 \end{pmatrix}$，$y_3 = \begin{pmatrix} 2 \\ -3 \end{pmatrix}$

我们需要寻找一个权重向量 $w = \begin{pmatrix} w_1 \\ w_2 \end{pmatrix}$，使得该样本集完美线性可分。

**请计算并回答：**
1. 经过课件中的**负规范化（Normalization）**处理后，写出这 3 个样本点转化后的新坐标向量（记为 $y_1', y_2', y_3'$）。
2. 写出参数 $w$ 必须满足的**统一不等式组**。
3. 测试两个候选参数：$w_A = \begin{pmatrix} 2 \\ 3 \end{pmatrix}$ 和 $w_B = \begin{pmatrix} 2 \\ 1 \end{pmatrix}$。请通过计算判断它们谁落在了**解区域（Solution Region）**内？

---

### ✍️ 详细解题步骤（人话版）

#### 第一步：施展反转魔法（负规范化）
根据规则：类 1 的样本保持不变，类 2 的样本通通乘以 $-1$：
* $y_1$ 属于类 1 $\implies$ 保持不变：
  $$y_1' = y_1 = \begin{pmatrix} 1 \\ 2 \end{pmatrix}$$
* $y_2$ 属于类 2 $\implies$ 整体乘以 $-1$：
  $$y_2' = -y_2 = \begin{pmatrix} 1 \\ -1 \end{pmatrix}$$
* $y_3$ 属于类 2 $\implies$ 整体乘以 $-1$：
  $$y_3' = -y_3 = \begin{pmatrix} -2 \\ 3 \end{pmatrix}$$

#### 第二步：列出解区域的“国界线不等式组”
规范化之后，所有样本的要求都统一成了 $(y_i')^T w > 0$。我们将向量内积展开：
1. 对于 $y_1'$：$1 \cdot w_1 + 2 \cdot w_2 > 0 \implies w_1 + 2w_2 > 0$
2. 对于 $y_2'$：$1 \cdot w_1 - 1 \cdot w_2 > 0 \implies w_1 - w_2 > 0$
3. 对于 $y_3'$：$-2 \cdot w_1 + 3 \cdot w_2 > 0 \implies -2w_1 + 3w_2 > 0$

只有同时满足这三个条件的 $w$，才算成功躺在**解区域**里。

#### 第三步：代入候选人，验明正身

##### 🟢 检验候选人 $w_A = \begin{pmatrix} 2 \\ 3 \end{pmatrix}$：
把 $w_1 = 2, w_2 = 3$ 代入三面墙的不等式中：
1. $2 + 2(3) = 8 > 0$ （满足第一面墙 ✅）
2. $2 - 3 = -1 < 0$ （**翻车！** 没满足第二面墙 ❌）
3. $-2(2) + 3(3) = 5 > 0$ （满足第三面墙 ✅）

由于违反了第二条约束，候选人 $w_A$ **没有**落在解区域内（它会把样本 $y_2$ 判错）。

##### 🔵 检验候选人 $w_B = \begin{pmatrix} 2 \\ 1 \end{pmatrix}$：
把 $w_1 = 2, w_2 = 1$ 代入：
1. $2 + 2(1) = 4 > 0$ （满足 ✅）
2. $2 - 1 = 1 > 0$ （满足 ✅）
3. $-2(2) + 3(1) = -1 < 0$ （**翻车！** 没满足第三面墙 ❌）

竟然也翻车了！说明 $w_B$ 同样**没有**落在解区域内。

##### 💡 额外加餐：真正的解是什么？
如果我们尝试 $w_{True} = \begin{pmatrix} 1 \\ 1 \end{pmatrix}$：
1. $1 + 2(1) = 3 > 0$ （满足 ✅）
2. $1 - 1 = 0$ （卡在边界上，不算严格大于 0 ❌）

如果我们换成 $w_{Final} = \begin{pmatrix} 1.1 \\ 1 \end{pmatrix}$：
1. $1.1 + 2 = 3.1 > 0$ （满足 ✅）
2. $1.1 - 1 = 0.1 > 0$ （满足 ✅）
3. $-2(1.1) + 3(1) = 0.8 > 0$ （满足 ✅）

三个全部严格大于 0！

### 🎯 最终标答
1. 负规范化后的新样本向量为：
   $$y_1' = \begin{pmatrix} 1 \\ 2 \end{pmatrix}, y_2' = \begin{pmatrix} 1 \\ -1 \end{pmatrix}, y_3' = \begin{pmatrix} -2 \\ 3 \end{pmatrix}$$
2. 统一的约束不等式组为：
   $$\begin{cases} w_1 + 2w_2 > 0 \\ w_1 - w_2 > 0 \\ -2w_1 + 3w_2 > 0 \end{cases}$$
3. 经计算，$w_A$ 和 $w_B$ 均有约束条件未满足，因此它们**都不在**解区域（Solution Region）内。而向量 $\begin{pmatrix} 1.1 \\ 1 \end{pmatrix}$ 则是一个完美的合理解。

# 线性可分与分类间隔（Margin）硬核计算题

## 📝 题目背景
已知经过负规范化（Normalization）处理后，我们手里有 2 个二维特征空间里的增广样本点：
* $y_1' = \begin{pmatrix} 2 \\ 1 \end{pmatrix}$
* $y_2' = \begin{pmatrix} 1 \\ 3 \end{pmatrix}$

现在我们设定一个现实中最看重的**目标分类间隔 $b = 4$**。也就是说，完美的权重向量 $w$ 必须严格满足约束条件组：
$$(y_i')^T w \ge 4$$

目前手头有两位候选的参数向量：
* 候选人 A：$w_A = \begin{pmatrix} 1 \\ 2 \end{pmatrix}$
* 候选人 B：$w_B = \begin{pmatrix} 2 \\ 1 \end{pmatrix}$

**请计算并回答：**
1. 列出该样本集在目标间隔 $b = 4$ 下的不等式约束控制组。
2. 通过计算分别判定 $w_A$ 和 $w_B$ 是否属于满足该安全间隔的**合理解**？
3. 如果不考虑安全间隔（即只需满足 $b > 0$ 判对即可），这两位候选人的表现有什么不同？由此谈谈为什么 `large margins are good`。

---

### ✍️ 详细解题步骤（人话版）

#### 第一步：建立带安全边界的“城墙约束组”
根据公式 $(y_i')^T w \ge b$，代入 $b = 4$ 和样本坐标展开：
1. 对于 $y_1'$：$2 \cdot w_1 + 1 \cdot w_2 \ge 4 \implies 2w_1 + w_2 \ge 4$
2. 对于 $y_2'$：$1 \cdot w_1 + 3 \cdot w_2 \ge 4 \implies w_1 + 3w_2 \ge 4$

#### 第二步：派候选人上场检测

##### 🟢 检验候选人 $w_A = \begin{pmatrix} 1 \\ 2 \end{pmatrix}$：
把 $w_1 = 1, w_2 = 2$ 代入约束组中：
1. $2(1) + 2 = 4 \ge 4$ （卡死在及格线上，勉强通过 ✅）
2. $1 + 3(2) = 7 \ge 4$ （远远高出及格线，完美通过 ✅）

由于同时满足了硬性指标，候选人 $w_A$ 是一个**满足 $b=4$ 间隔的合格解**！

##### 🔴 检验候选人 $w_B = \begin{pmatrix} 2 \\ 1 \end{pmatrix}$：
把 $w_1 = 2, w_2 = 1$ 代入约束组中：
1. $2(2) + 1 = 5 \ge 4$ （顺利通过 ✅）
2. $2 + 3(1) = 5 \ge 4$ （顺利通过 ✅）

太棒了！候选人 $w_B$ 同样也**满足 $b=4$ 间隔的合格解**！

#### 第三步：深度复盘——谁才是更安全的“最优解”？
我们来看看在没有归一化的情况下，他们各自能撑开的**极限安全间隔 $b$** 是多少：
* 对于 $w_A$：它在两个样本上算出来的数字分别是 $4$ 和 $7$。取短板（最小值），它的极限安全边界是 **$b_{max} = 4$**。
* 对于 $w_B$：它在两个样本上算出来的数字分别是 $5$ 和 $5$。取短板（最小值），它的极限安全边界是 **$b_{max} = 5$**。

### 🎯 最终标答
1. 目标间隔下的约束不等式组为：
   $$\begin{cases} 2w_1 + w_2 \ge 4 \\ w_1 + 3w_2 \ge 4 \end{cases}$$
2. 经计算，$w_A$ 和 $w_B$ 带入后的结果均大于或等于 $4$，因此它们**都属于**满足该分类间隔的合理解。
3. 灵魂对比：虽然在无边界要求（$b>0$）时，两个解都能做到 $100\%$ 判对。但如果看极限承压能力，$w_B$ 能够提供更大的分类间隔（$b=5 > 4$）。在几何上，$w_B$ 处于解区域更中心的位置，面对未来测试集数据的扰动时，它翻车的概率比贴着及格线（$4$）的 $w_A$ 更小。这就完美印证了 **“Large margins are good”** 的直觉。

# 梯度下降与批感知机（Batch Perceptron）单步迭代计算题

## 📝 题目背景
假设我们手里有 3 个已经过负规范化（Normalization）处理的增广样本向量：
* $y_1 = \begin{pmatrix} 1 \\ 2 \end{pmatrix}$
* $y_2 = \begin{pmatrix} 2 \\ -1 \end{pmatrix}$
* $y_3 = \begin{pmatrix} -1 \\ 1 \end{pmatrix}$

现在，我们设定感知机算法的**学习率 $\eta = 1$**。系统赋予的初始权重向量为：
$$w^{(1)} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$$

**请计算并回答：**
1. 在当前权重 $w^{(1)}$ 下，代入这 3 个样本，找出哪些样本被模型**判错**了？写出判错集合 $M(w^{(1)})$。
2. 计算当前状态下的感知机损失函数总痛感值 $J_p(w^{(1)})$。
3. 计算当前的梯度 $\nabla J_p(w^{(1)})$，并利用批感知机更新公式，算出**下一步的权重向量 $w^{(2)}$**。

---

### ✍️ 详细解题步骤（人话版）

#### 第一步：抓出“判错大本营”里的倒霉蛋
规范化后的标准是：只要 $y_i^T w > 0$ 就是判对， $y_i^T w \le 0$ 就是判错。我们挨个做内积：
* **对于 $y_1$：**
  $$y_1^T w^{(1)} = 1 \cdot 1 + 2 \cdot 0 = 1 > 0 \quad \text{（判对 ✅）}$$
* **对于 $y_2$：**
  $$y_2^T w^{(1)} = 2 \cdot 1 + (-1) \cdot 0 = 2 > 0 \quad \text{（判对 ✅）}$$
* **对于 $y_3$：**
  $$y_3^T w^{(1)} = (-1) \cdot 1 + 1 \cdot 0 = -1 \le 0 \quad \text{（判错 ❌）}$$

**【阶段结论 1】** 判错集合里只有 1 个倒霉蛋：$M = \{y_3\}$。

#### 第二步：清算当前账本的总痛感
根据公式 $J_p(w) = \sum_{y \in M} -y^T w$，我们把判错集合里的元素放进来算账：
$$J_p(w^{(1)}) = - (y_3^T w^{(1)}) = -(-1) = \mathbf{1}$$
当前模型的总痛感得分为 $1$。

#### 第三步：计算梯度并向山谷迈进（更新权重）
1. 根据公式，当前的梯度 $\nabla J_p$ 是所有判错样本之和取负号：
   $$\nabla J_p(w^{(1)}) = -y_3 = -\begin{pmatrix} -1 \\ 1 \end{pmatrix} = \begin{pmatrix} 1 \\ -1 \end{pmatrix}$$
2. 利用梯度下降（批感知机）更新公式 $w^{(2)} = w^{(1)} + \eta \sum_{y \in M} y$：
   $$w^{(2)} = \begin{pmatrix} 1 \\ 0 \end{pmatrix} + 1 \cdot \begin{pmatrix} -1 \\ 1 \end{pmatrix} = \begin{pmatrix} 1 + (-1) \\ 0 + 1 \end{pmatrix} = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$$

#### 💡 额外验证：走完这一步，世界变好了吗？
我们用崭新的权重 $w^{(2)} = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$ 重新去测一下刚才那个判错的 $y_3$：
$$y_3^T w^{(2)} = (-1) \cdot 0 + 1 \cdot 1 = 1 > 0 !$$
看！刚才不及格的 $y_3$，在更新完权重后，瞬间变成了完美的正数（判对）。感知机通过一次梯度下降，成功修正了自己的错误。

### 🎯 最终标答
1. 在 $w^{(1)}$ 下，只有样本 **$y_3$** 被判错，因此判错集合 $M = \{y_3\}$。
2. 当前的感知机损失总痛感 $J_p(w^{(1)}) = 1$。
3. 当前计算得到的梯度为 $\nabla J_p(w^{(1)}) = \begin{pmatrix} 1 \\ -1 \end{pmatrix}$，更新后的下一步权重向量为 **$w^{(2)} = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$**。

# 固定步长单样本感知机（Single-Sample Perceptron）迭代计算题

## 📝 题目背景
已知有 3 个已经过负规范化（Normalization）处理的增广样本向量，它们一直在排队循环等待模型检测：
* $y^1 = \begin{pmatrix} 1 \\ 1 \end{pmatrix}$
* $y^2 = \begin{pmatrix} 1 \\ -2 \end{pmatrix}$
* $y^3 = \begin{pmatrix} -2 \\ 1 \end{pmatrix}$

我们使用固定步长单样本感知机算法（学习率 $\eta = 1$）。系统随机赋予的初始权重向量为：
$$w^{(1)} = \begin{pmatrix} 0 \\ -1 \end{pmatrix}$$

模型将按照 $y^1 \rightarrow y^2 \rightarrow y^3$ 的物理顺序一个一个进行流水线审查。只要遇到判错的样本，**立刻原地更新权重**，并带着新权重审查下一个样本。

**请计算并回答：**
1. 审查第一个样本 $y^1$ 时，模型是否判错？更新后的权重 $w^{(2)}$ 是多少？
2. 带着上一步的成果审查第二个样本 $y^2$ 时，模型是否判错？更新后的权重 $w^{(3)}$ 是多少？
3. 带着成果审查第三个样本 $y^3$ 时，模型是否判错？更新后的权重 $w^{(4)}$ 是多少？

---

### ✍️ 详细解题步骤（人话版）

#### 1️⃣ 第一轮：审查样本 $y^1$
我们用当前的初始权重 $w^{(1)} = \begin{pmatrix} 0 \\ -1 \end{pmatrix}$ 去和 $y^1$ 做内积运算：
$$(y^1)^T w^{(1)} = 1 \cdot 0 + 1 \cdot (-1) = -1 \le 0$$
* **判定结果：** 算出来是负数，**判错 ❌！**
* **原地纠错：** 触发单样本更新公式 $w^{(2)} = w^{(1)} + y^1$：
  $$w^{(2)} = \begin{pmatrix} 0 \\ -1 \end{pmatrix} + \begin{pmatrix} 1 \\ 1 \end{pmatrix} = \begin{pmatrix} 0 + 1 \\ -1 + 1 \end{pmatrix} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$$

#### 2️⃣ 第二轮：审查样本 $y^2$
此时权重已经升级为 $w^{(2)} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$。我们用它去审查队伍里的第二个蛋 $y^2$：
$$(y^2)^T w^{(2)} = 1 \cdot 1 + (-2) \cdot 0 = 1 > 0$$
* **判定结果：** 算出来是正数，**判对 ✅！**
* **原地纠错：** 判对了不需要任何调整，参数无缝继承。
  $$w^{(3)} = w^{(2)} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$$

#### 3️⃣ 第三轮：审查样本 $y^3$
此时权重为 $w^{(3)} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$。我们用它去审查第三个蛋 $y^3$：
$$(y^3)^T w^{(3)} = (-2) \cdot 1 + 1 \cdot 0 = -2 \le 0$$
* **判定结果：** 算出来是负数，**又判错 ❌！**
* **原地纠错：** 再次触发单样本更新公式 $w^{(4)} = w^{(3)} + y^3$：
  $$w^{(4)} = \begin{pmatrix} 1 \\ 0 \end{pmatrix} + \begin{pmatrix} -2 \\ 1 \end{pmatrix} = \begin{pmatrix} 1 + (-2) \\ 0 + 1 \end{pmatrix} = \begin{pmatrix} -1 \\ 1 \end{pmatrix}$$

#### 💡 课后复盘：收敛定理显灵了吗？
队伍的第一轮流水线走完了，我们得到了最终的权重 $w^{(4)} = \begin{pmatrix} -1 \\ 1 \end{pmatrix}$。
根据感知机收敛定理，我们来用这个最新参数重头把 3 个样本全体复查一遍：
* 对于 $y^1$：$(-1) \cdot 1 + 1 \cdot 1 = 0$ （卡在边界，如果重新过流水线它会再次触发微调 ✅）
* 对于 $y^2$：$(-1) \cdot 1 + 1 \cdot (-2) = -3$ （会触发微调）

只要数据本身线性可分，这个流水线再循环跑几轮，这个参数就绝对能彻底稳死在解区域里。

### 🎯 最终标答
1. 审查 $y^1$ 时**判错**，更新后的权重向量为：
   $$w^{(2)} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$$
2. 审查 $y^2$ 时**判对**，权重保持不变：
   $$w^{(3)} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$$
3. 审查 $y^3$ 时**判错**，更新后的最终权重向量为：
   $$w^{(4)} = \begin{pmatrix} -1 \\ 1 \end{pmatrix}$$

## 📝 题目
作为第一代机器学习算法，1957年提出的感知机（Perceptron）算法存在哪些核心的理论与工程局限性？针对这些局限性，现代机器学习（如 SVM、Logistic Regression）分别给出了怎样的改进思路？

---

### ✍️ 参考标答（硬核高分版）

#### 1. 核心局限性梳理
* **解的非唯一性与鲁棒性缺失（无 Margin 保证）：** 当数据线性可分时，算法表现出对初始权重 $w^{(1)}$ 和样本输入顺序的强依赖性。算法一旦满足条件便立即终止，无法保证寻找全局最优解，往往导致最终决策边界紧贴样本，泛化能力（Generalization Ability）极差。
* **线性不可分情况下的非收敛性（陷入死循环 Cycle）：** 面对现实中普遍存在的线性不可分（Non-separable）数据集，算法会产生“鬼打墙”现象，参数权重在空间中无限震荡且周期极长，无法自动终止，工程上极难捕捉和调试。
* **缺乏概率学阐释（No Probabilistic Interpretation）：** 感知机输出为硬分类标签（Hard Label），无法提供样本属于某一类别的后验概率预测 $P(c_i \mid x)$，在需要置信度评估的场景（如医疗诊断）中无法落地。

#### 2. 现代机器学习的进化平替路径
针对上述痛点，后世的算法大牛们给出了完美的自救方案，直接开启了统计学习的黄金时代：

| 感知机的痛点缺陷 | 现代算法的救场方案 | 核心数学机制 |
| :--- | :--- | :--- |
| **无安全边界，解靠运气** | **支持向量机（SVM）** | 引入超平面几何间隔，通过拉格朗日乘子法求解凸二次规划问题，最大化分类间隔（**Maximal Margin**），寻找唯一且最稳健的国界线。 |
| **遇到不可分直接死循环** | **软间隔 SVM / 逻辑回归** | 1. SVM 引入松弛变量 $\xi_i$ 和合页损失（Hinge Loss），允许少量犯错，保证不可分时也能收敛。<br>2. 逻辑回归引入交叉熵损失，全盘连续可导。 |
| **没有概率输出，太死板** | **逻辑回归（Logistic Regression）** | 摒弃感知机的阶跃激活函数，改用双曲正切或 **Sigmoid 函数**，将输出完美映射到 $(0,1)$ 区间，赋予了模型纯正的**最大似然与后验概率**灵魂。 |

#### 3. 历史地位总结
尽管局限性明显，但感知机算法作为多层感知机（MLP）和深度学习（Deep Learning）的基石，首次在工程上实现了“根据错误自动调整权重”的闭环。其在 1957 年利用模拟硬件（电动机与变阻器）的成功落地，证实了机器自适应学习的可行性，具有不可磨灭的里程碑意义。
